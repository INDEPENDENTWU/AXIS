# AXIS 8.9 — Quiet Intelligence

AXIS 8.9 keeps the proven 8.8.4 interaction model intact and adds intelligence only where it removes friction.

## Atomic detail handoff

`记录 -> 本次训练 -> 单项详情` prepares media and the complete event detail off-screen, decodes photo assets, then swaps title and body in one animation frame. An already-open detail sheet is never closed/reopened and no loading overlay is introduced.

## Local Vision v2

Local recognition remains the first response path and works without network AI. v2 adds richer structural signatures, frame-quality-aware selection, diverse per-equipment memory and usage priors. A local match can preselect immediately; frontier vision may verify it in the background without blocking the user.

## Frontier Vision

The browser sends only selected scan frames plus a sanitized AXIS catalog. The server validates every returned equipment ID against that request catalog. It cannot invent an equipment name.

Provider routing is server-owned:

1. OpenAI GPT-5.6 Sol when `OPENAI_API_KEY` is configured.
2. Gemini 3.1 Pro Preview when `GEMINI_API_KEY` is configured.
3. Existing Bailian/Qwen configuration remains supported.

A second provider/model is called only for a genuinely ambiguous, sufficiently clear capture. Close model disagreement becomes `needsConfirmation`; AXIS prefers asking for one tap over returning a confident wrong machine.

## Catalog and search

The existing catalog UI remains the owner. 8.9 only enriches data with additional plate-loaded/iso-lateral press and row variants, assisted pull-up, machine lateral/arm variants, V squat, glute drive, dedicated calf machines, stair climber, SkiErg, sled/carry variants, and common-language search such as `练屁股`, `大腿后面`, `下背`, `手腕`, `握力`, `大腿内侧` and `小腿前面`.

## Rest Speak

Rest Speak is an optional accessory and is **off by default**.

It:

- reads the existing between-set rest state;
- uses the existing `#v87Rest` slot;
- stores its own preferences/exposure history outside training metadata;
- creates no interval, overlay, observer, timer, training state, timeline state, capture state or sound owner;
- never autoplays audio;
- disappears automatically outside a rest state;
- never changes active-card geometry.

Chinese-native users can choose English/Japanese/Korean. English-native users can choose Chinese/Japanese/Korean. Each rest exposure contains one short spoken phrase plus an immediate meaning; Japanese/Korean/Chinese include a light pronunciation aid. Phrase exposure rotates passively with no quiz, streak or mandatory action. Tapping the phrase is optional and only speaks that phrase through the browser speech engine.

## Compatibility

8.9 keeps the 8.8.4 direct active-control owner, natural page scrolling, completed-item archive, training trajectory, canonical watermark owner and all existing capture flows unchanged.

## Release gates

`axis-build.json` must include:

- `detailAtomicHandoff`
- `localVisionV2`
- `frontierVisionCatalogContract`
- `frontierVisionProviderRouter`
- `restSpeakPassive`
- `restSpeakNoGeometryOwner`
- `expandedSearchVocabulary`

The dedicated Chromium and iPhone WebKit smoke verifies detail atomicity, Rest Speak geometry neutrality/isolation, active-control ownership, Local Vision/catalog markers and colloquial search.
