# AXIS 8.8.2 — Home Transition Refinement

## Reason

The 8.8.2 `现在` surface was useful as a state model but visually duplicated the already-established 8.8.1 active-training hierarchy. During an active item it repeated item state, elapsed time and session facts that already belonged to the original `进行中` session header and the v87 current-item card.

## Preserved unchanged

The following 8.8.1 surfaces remain canonical and are not redesigned by this repair:

- `进行中` session header;
- total live session timer;
- `长按结束` session action;
- recorded-item / total-set metrics;
- v87 current-item card, countdown, pause/resume, set completion and finish interaction.

## New visibility rule

The 8.8.2 `现在` surface no longer competes with active training.

It is hidden while:

- a session has started but the first item has not started;
- an item is active;
- an item is paused;
- the user is in within-item set rest, including normal / slightly long / substantially long rest states.

It remains available when it adds information that the 8.8.1 active hierarchy does not already own:

- idle / pre-training state;
- between-session recovery context;
- the transition after one exercise/item is completed and before the next item starts.

## Inter-item transition design

The between-item state is deliberately compact rather than a second dashboard. It contains only:

- transition status (`项目间歇`, `可以开始下一项`, or `间歇过长`);
- elapsed interval since the previous item completed;
- previous item name plus the suggested interval / amount beyond the suggestion;
- one thin progress rail.

The circular dial and two fact columns are removed from this state. Session-total time, recorded-item count, active-item details and long-press instructions are intentionally not repeated.

## Performance / ownership

- `app.js` remains the single Home state owner through the existing compiler fragment.
- The existing one-second Home tick is reused; no observer, second timer or duplicated DOM owner is added.
- Visibility is a single `hidden` state plus one Today-view class.
- Geometry is static CSS.
- The base 8.8.1 values for Today header spacing, active `liveHead`, compact metrics and long-press control are checked at build time before refinement CSS is emitted.

## Regression gate

`AXIS Home Transition Gate` runs in Chromium and iPhone-like WebKit and verifies:

- the Now surface is absent during the active-session and active-item hierarchy;
- 8.8.1 session timer and long-press finish remain visible;
- 8.8.1 active spacing remains exact;
- after an item is completed, the Now surface returns only as a compact inter-item transition;
- transition UI has no dial, duplicate fact row, session-total copy, recorded-count copy or long-press copy.
