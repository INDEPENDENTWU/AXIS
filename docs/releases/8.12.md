# AXIS 8.12

8.12 expands the optional Language Studio while preserving the 8.11 training, State Field and local-first service contracts.

## Release contract

- 19,584 new learning units: 4,896 each for English, Japanese, Korean and Chinese.
- 25,716 total units available after inherited content.
- English total: 10,632.
- Japanese, Korean and Chinese totals: 5,028 each.
- Dialogue depth selectable at 4, 8 or 12 turns.
- Seven-stage learning loop: meaning, noticing, retrieval, response, shadow, transform, review.
- Practice modes include dialogue, listening, shadowing, recall, dictation and transformation.
- Language Studio does not require network access, does not autoplay speech and does not own training state.
- Inherited 8.11 learning, State Field and cloud/AI contracts remain release-blocking.

## Engineering

8.12 adds dedicated browser and experience gates and extends Production verification to the 8.12 contract while keeping the canonical single-runtime artifact.

The release continues to use `node build-release.mjs` as the only provider-facing build command.

## Scope note

Language Studio is an optional rest/learning channel, not a second top-level product identity. The next release cycle shifts focus from content expansion to the training Runtime described in `docs/ROADMAP.md`.
