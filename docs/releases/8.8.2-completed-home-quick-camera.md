# AXIS 8.8.2 — Completed Home + Quick Camera Refinement

## Home after a finished workout

A finished workout is no longer presented as a pseudo-physiological recovery dashboard.

When the latest session ended today, Home now shows one restrained completion summary:

- `今天完成`;
- `训练已记录`;
- the real session duration;
- item count, completed strength-set count and finish time.

The percentage dial, progress rail and duplicate fact columns are removed from this state. A session shorter than one minute is rendered as `<1分钟`, never `0分钟`.

On later days, the same surface becomes a neutral training-interval reference (`距上次训练`) with the previous duration and the user's usual interval. It does not claim a precise body-recovery percentage.

The older `接着上次 / 只改变化` Home list is retired. Its continuation purpose already belongs to Quick Record's `最近` list, so Home no longer duplicates it.

Idle Home refreshes once per minute; active training remains one-second precision.

## Quick Record media

`补拍照片`, `3秒视频` and `5秒视频` remain Quick Record affordances, but the camera entry is now owned by the same canonical capture function as the main `拍摄记录` button.

The root issue was structural: Quick Record kept the `v8-quick` class while trying to reveal `#captureStage`, while the established Quick Record CSS intentionally hides that stage. The new camera owner temporarily leaves editor mode while capturing, then restores Quick Record review mode after media is captured.

This guarantees that `补拍照片` opens the real camera surface rather than a hidden or partial editor state.

## Regression coverage

The Home Transition Gate now validates in Chromium and WebKit:

- same-day completed Home has no recovery percentage UI;
- no dial / rail / duplicate facts after finishing;
- no duplicate `接着上次` Home list;
- idle Home uses the lower-frequency timer;
- later sessions use neutral training-interval copy;
- Quick Record photo capture visibly enters the canonical camera surface;
- main capture and Quick Record media report the same canonical camera owner.
