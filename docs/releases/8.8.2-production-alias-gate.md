# AXIS 8.8.2 — Public Production Alias Gate Repair

## Scope

This repair changes **release verification only**. It does not change AXIS product runtime, UI, user data, camera behavior, recording behavior, media persistence, Home intelligence, exercise catalog, Quick Record or sound playback.

## What happened

After AXIS 8.8.2 PR #16 was merged, `main` moved to merge commit:

`a753370ff80b5721655cb102f4ee72f3362c7bba`

Vercel reported the Production deployment for that exact commit as successful. The fixed public alias `https://axis-five-puce.vercel.app` also began serving `axis-build.json` with:

- `sourceCommit = a753370ff80b5721655cb102f4ee72f3362c7bba`;
- `version = 8.8.2`;
- `baseVersion = 8.8.2`;
- `architecture = canonical-single-runtime`.

The **AXIS Public Production Alias Gate** still failed. The failure was not a stale alias and not a failed deployment.

## Root cause

The public-alias validator still contained the 8.8.1 sound-owner assertion:

`canonical.activeCountdown.toneOwner === "v87"`

AXIS 8.8.2 intentionally converged automatic sound ownership to:

`canonical.activeCountdown.toneOwner === "v8710-sound-ui.js"`

with:

`canonical.activeCountdown.automaticTrigger === "countdown-zero-only"`

The validator therefore rejected a correct 8.8.2 Production manifest even while its source SHA, release version and architecture were already exact.

## Repair

`.github/workflows/axis-public-production-alias-gate.yml` now verifies the actual AXIS 8.8.2 release contract:

- exact deployed `sourceCommit`;
- exact public/base version;
- `canonical-single-runtime`;
- one initial JavaScript request and zero dynamic runtime chunks;
- canonical watermark/location/preferences contracts;
- inherited 8.8.1 planner/countdown/brand gates;
- `v8710-sound-ui.js` as the automatic countdown sound owner;
- `countdown-zero-only` as the automatic trigger;
- Home single-owner/adaptive-rest gates;
- Personal Visual Memory gate;
- Quick custom-item and Quick media gates;
- immutable active-card geometry gate;
- countdown-only automatic-sound gate;
- expanded exercise library and waist anatomy gates;
- durable-release-log gate;
- WebKit-safe Media Store gate;
- canonical Media Store owner `app.js`, write format `arraybuffer-v1`, and `webkitSafe = true`.

The exact-SHA requirement is preserved. The repair does not weaken, bypass or shorten Production validation; it makes the fixed-public-alias gate stricter and release-aware for 8.8.2.

## Previous evidence

Before this validator repair:

- AXIS 8.8.2 feature branch HEAD `8ff69cf97f1bc46ace00d1b86525098509d3ff1f` passed Chromium Runtime, iPhone/WebKit Runtime, full Product Matrix, Reminder/Layout in both engines and Deployment Policy;
- PR #16 merged successfully;
- Vercel Production deployment for merge SHA `a753370ff80b5721655cb102f4ee72f3362c7bba` completed successfully;
- Production Deployment Gate `31927271552` passed;
- the fixed public alias was observed serving that exact merge SHA and AXIS 8.8.2 manifest;
- Public Production Alias Gate `31927271637` false-failed solely because of the stale `toneOwner === "v87"` assertion.

## Completion rule

This repair is complete only when its own branch gates pass, the repair is merged to `main`, the resulting new `main` SHA is deployed, and the **corrected Public Production Alias Gate** verifies that the fixed public alias serves that exact new SHA with the full AXIS 8.8.2 contract.
