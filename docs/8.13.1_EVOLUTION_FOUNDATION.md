# AXIS 8.13.1 · Evolution Foundation

## Purpose

8.13.1 is not a feature expansion. It prepares the current AXIS runtime and data model for the future Evolution layer without changing existing recording ownership.

The priority is preserving the reliability of 8.12 while making the product direction clearer:

- recording remains authoritative;
- historical data remains compatible;
- future Evolution objects are derived from real events;
- no forced content creation is introduced.

## Product shift

Current:

`Workout -> Record -> History`

Future:

`Reality -> Capture -> Encounter -> Evolution`

8.13.1 only establishes the foundation.

## 8.13.1 scope

### 1. Stabilize reality data

Verify that every completed training event has:

- activity identity;
- timestamps;
- active intervals;
- completion state;
- related equipment/exercise reference;
- optional media reference.

No synthetic data should be created for missing history.

### 2. Evolution-ready aggregation

Introduce read-only derived calculations:

- first encounter;
- latest encounter;
- encounter count;
- elapsed time span;
- historical best values where evidence exists.

These values do not replace existing history.

### 3. Trends migration preparation

The existing Trends interface should move toward evidence-based presentation.

Avoid:

- generic charts without meaning;
- motivational copy;
- artificial scores.

Prefer:

- concrete changes;
- before/after comparison;
- real timeline relationships.

### 4. Media foundation

Prepare references for:

- photos;
- videos;
- future Live Photo support.

Media is evidence attached to reality, not user-generated content required for success.

## Interaction rules

AXIS text should remain:

- direct;
- specific;
- professional;
- calm.

Avoid:

- AI assistant style;
- tutorials inside interfaces;
- slogans;
- unnecessary explanations.

Examples:

Good:

`首次记录 25kg`

`最近一次 40kg`

Avoid:

`继续坚持，你会看到更多变化`

## Regression requirements

8.13.1 must not break:

- recording;
- pause/resume;
- completion;
- custom equipment;
- media capture;
- offline behavior;
- existing stored sessions.

## Not included

- social feed;
- sharing network;
- mandatory photo/video capture;
- AI coach;
- large UI rewrite.

The goal is a stable bridge from the current AXIS runtime to the future Personal Evolution system.
