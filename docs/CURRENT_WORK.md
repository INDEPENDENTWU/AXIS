## Active change — AXIS 8.14 Evolution Objects

- Branch: `web-814-evolution-objects`.
- PR: **#65 — AXIS 8.14 — Evolution Objects**.
- Base: production `main` at `a803df95075fac5e28c46dfd554cc3ecdbca6388`.
- Candidate public/base version: **8.14**.
- Product objective: move from a truthful Reality → Encounter projection to the first directly perceptible Evolution object, without turning Trends into a dashboard or creating a new data-entry workflow.

### Product behavior

- 8.13.1 remains the top-level Trends owner: `v8131-evolution-field`.
- 8.14 adds the narrow in-place sub-owner: `v814-evolution-objects`.
- Expanding a sealed Session still shows its real recorded activities.
- Each activity row is now a semantic button carrying the existing stable activity identity.
- Tapping an activity reveals an Evolution Object **inside the same Trends surface**; it does not open a modal, sheet or separate dashboard.
- The object projects only facts already present in canonical records:
  - encounter count;
  - elapsed time span;
  - first encounter;
  - latest encounter;
  - literal directly comparable delta when one exists;
  - existing media-evidence count.
- A first-only encounter renders `第一次 · 也是最近一次` and never invents progress.
- Repeated same-day encounters remain separate encounters.
- Literal changes such as `重量 30kg → 35kg` or `总次数 30 → 36` are evidence presentation, not a score or interpretation.
- No `进步 / 提升 / 改善 / 更好 / 评分 / 分数` language is generated by the 8.14 object owner.

### Ownership boundary

8.14 does **not** add:

- a training/session writer;
- a new persistence schema;
- writes to `axis_v60_state` or `axis_v8_meta`;
- network requests;
- AI inference, scoring or advice;
- polling/MutationObserver/ResizeObserver ownership;
- Replay or generated video;
- iOS changes.

`window.__AXIS_EVOLUTION_OBJECTS__` is a read-only resolver over existing sealed Sessions. 8.13.1 metadata activity evidence remains the source of truth for session fingerprint/lifecycle presentation.
